# Week 5：macOS 几何吸附

这些步骤要在 macOS 13 或更高版本上执行。云端和 Linux 不能跑 `pnpm tauri dev` 的真实窗口，所以吸附、点击、跟随、切换空间和拆卸都要在 Mac 上点验。下面的命令只在 Mac 上有意义。

```bash
pnpm install
pnpm tauri dev
```

退出时点窗口左上角的红色关闭按钮。关闭时会先把已经吸附的窗口还原，再结束进程。

这一周只打开一条吸附通路，目标是目录里已经确认的 Electron 应用 **Claude Desktop**（`claude-desktop`，Bundle ID `com.anthropic.claudefordesktop`）。ChatGPT Desktop、Cursor Desktop 和其他已确认的桌面应用仍然只检测，不会被移动。WorkBuddy、Accio Work、Harness 的 Bundle ID 保持为空。

macOS 不能把别的进程的窗口收成子视图，所以这里不做 `SetParent`，也不做窗口镜像。主窗口保持不透明。分屏格里放一块透明占位，再用辅助功能去掉目标窗口的边框，把那个窗口对齐到占位上。跟随用 `CVDisplayLink` 对齐刷新；如果 DisplayLink 起不来，改用 60fps 的定时器。位置、大小、Space，以及和主窗口的前后关系都会在这个循环里同步。

如果系统不允许去掉边框，或者不允许把窗口挪进占位，就改成窗口并列跟随：边框留着，窗口贴在主窗口旁边，并跟着主窗口移动。不会去截屏或镜像。

## 吸附 Claude Desktop

1. 安装并打开 Claude Desktop，确认侧栏「桌面 → 运行中」里出现 Claude Desktop。
2. 如果顶部还没有「已授权」，按 `docs/week4-detection-a11y.md` 完成辅助功能。未签名的 debug 构建换过路径后，系统设置里的开关可能要重新打开。
3. 先点右侧要放入的那一格，再点运行中 Claude Desktop 旁边的「吸附」。
4. 格子标题变成「Claude Desktop」，格子主体是一块虚线标出的透明占位。Claude 的窗口应盖住这块占位，标题栏按钮不再挡在格子里。
5. 点 Claude 窗口里的输入框或按钮，确认点得到，焦点在 Claude 里，而不是穿透到下面的网页。
6. 格子顶上的「拆卸」留在占位外面，仍然点得到。

占位只覆盖格子标题以下的区域。壳窗口本身不透明，其他格子和标题栏不受影响。

## 跟随

吸附之后：

1. 拖动 UniWorkspace 主窗口。Claude 应跟着走，不留下一截旧位置。
2. 拖动主窗口边缘改变大小，或切换单窗 / 1:1 / 田字格。占位变了之后，Claude 的大小跟着变。
3. 切换到另一个桌面空间（Space）。Claude 应出现在主窗口所在的那个空间，而不是留在原来的空间。
4. 再切回来。两者仍在一起，Claude 仍盖在占位上，点得到。

种子版可以有轻微缝隙。抖动和全屏边界留到第 6 周，这一周只要跟得上。

如果 Claude 被最小化，或辅助功能拒绝继续移动，吸附会自己结束。这一格下面的网页重新出现，侧栏说明原因。边框没有写回去时，`snap-recovery.json` 会留着，下次启动再试，不会当成已经还原。

## 拆卸

1. 点格子上的「拆卸」，或把布局收成不再包含这一格，或清空这一格。
2. Claude 的标题栏和窗口按钮回来。
3. 窗口回到吸附前的位置和大小，不再强制盖在 UniWorkspace 上面。
4. 侧栏出现「已还原边框和层级。」
5. 如果这一格下面本来有网页，拆卸后网页重新出现。

关闭 UniWorkspace 的红色按钮也会做同一次还原。不要用强制退出代替它。

如果进程在吸附中被强制杀掉，下一次正常启动会读 `~/Library/Application Support/com.uniworkspace.ai/snap-recovery.json`，把 Claude 的边框和位置放回去，然后删掉这个文件。不要手改这个文件。辅助功能还没打开时，文件会留着，等授权之后再试。

## 辅助功能被拒绝

1. 点「仅使用网页」，或者在系统对话框里不允许。
2. 点 Claude Desktop 的「吸附」。
3. 侧栏说明需要辅助功能，并写明窗口没有被移动。Claude 停在原来的位置，边框也不变。
4. 侧栏点 ChatGPT 或 Claude 网页，分屏、登录和自定义链接仍可使用。应用不退出。

启动时不会自己弹出系统授权。

## 并列跟随

如果辅助功能读得到窗口，但不允许去掉边框，或写不进占位矩形：

1. 格子里会说明已经改为在主窗口旁边跟随，边框还在。
2. Claude 出现在主窗口右侧；右侧不够时改到左侧。
3. 拖动、缩放主窗口和切换空间时，它仍跟着走，并且可以点击。
4. 拆卸后它回到吸附前的位置。边框本来就没有被去掉。

如果连旁边的位置也不允许写，窗口留在原处，侧栏说明没有移动它，不会反复重试。

## 指定窗口仍然不动

1. 点「指定窗口」，把任意可见窗口加入侧栏。
2. 那个窗口的位置、大小和层级都不变。
3. 这一行没有「吸附」。指定只是列出。

## 不要回归的部分

已确认网页的分区、登录态、单窗 / 1:1 / 田字格，以及只重建崩溃的那一格，都还在。ComfyUI 仍只打开 `http://127.0.0.1:8188/`。全局热键仍未注册。

Accio Work、Cursor、Harness 的网页地址保持为空。WorkBuddy、Accio Work、Harness 的桌面 Bundle ID 保持为空。Cursor 的 Bundle ID 只记在 `cursor-desktop`。

## 这一周明确不做

不把其余已确认的桌面应用接上吸附。不全屏专项、不处理「对方先退出」的全部边界，也不把跟随缝隙压到第 6 周的标准。不做全局热键，不做安装包，不做窗口镜像，不做 Windows 或 Linux 构建。
