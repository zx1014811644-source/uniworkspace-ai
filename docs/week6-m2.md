# Week 6：已确认桌面端收口（M2）

这些步骤要在 macOS 13 或更高版本上执行。云端和 Linux 不能跑 `pnpm tauri dev` 的真实窗口，所以吸附、点击、跟随、全屏、Space 边缘、对方先退出和拆卸都要在 Mac 上点验。下面的命令只在 Mac 上有意义。

```bash
pnpm install
pnpm tauri dev
```

退出时点窗口左上角的红色关闭按钮。关闭时会先把已经吸附的窗口还原，再结束进程。不要用强制退出来代替它。

这一周把 Week 5 的几何吸附扩到目录里 **Bundle ID 已经确认** 的全部 macOS 桌面应用。没有确认桌面 ID 的应用继续只走网页，不阻挡 M2。macOS 不能把别的进程的窗口收成子视图，所以这里不做 `SetParent`，也不做窗口镜像。

同一时间只吸附一个桌面窗口。再点另一个已确认应用的「吸附」时，会先还原上一个，再吸附新的。多窗口应用吸附该进程里面积最大的普通窗口。

跟随用 `CVDisplayLink`，并尽量绑到主窗口所在的那块显示器上，用来减轻拖动抖动。DisplayLink 起不来时，改用 60fps 定时器。种子版允许拖动时有轻微缝隙。退出、卸下格子或对方先退出之后，不允许留下无边框孤窗。

## 会吸附的应用

只使用目录里已经确认的 Bundle ID：

| 应用 | 目录 id | Bundle ID |
| --- | --- | --- |
| ChatGPT Desktop | `chatgpt-desktop` | `com.openai.codex` |
| Claude Desktop | `claude-desktop` | `com.anthropic.claudefordesktop` |
| LM Studio | `lm-studio` | `ai.elementlabs.lmstudio` |
| Gemini Desktop | `gemini-desktop` | `com.google.GeminiMacOS` |
| Kimi Desktop | `kimi-desktop` | `com.moonshot.kimichat` |
| 豆包 Desktop | `doubao-desktop` | `com.bot.pc.doubao` |
| Cursor Desktop | `cursor-desktop` | `com.todesktop.230313mzl4w4u92` |

`com.todesktop.230313mzl4w4u92` 只属于 `cursor-desktop`。WorkBuddy、Accio Work、Harness 的桌面 Bundle ID 保持为空。Accio Work、Cursor、Harness 的网页地址保持为空。不要把备注里的候选值写进目录。

建议先点验 ChatGPT Desktop、Claude Desktop 和 LM Studio，再对其余四个各做一遍下面的吸附、跟随、点击和拆卸。

## 吸附

1. 安装并打开要测的桌面应用，确认侧栏「桌面 → 运行中」里出现它，并且名字旁边有「吸附」。
2. 如果顶部还没有「已授权」，按 `docs/week4-detection-a11y.md` 完成辅助功能。未签名的 debug 构建换过路径后，系统设置里的开关可能要重新打开。
3. 先点右侧要放入的那一格，再点该应用旁边的「吸附」。
4. 格子标题变成这个应用的名字，格子主体是一块虚线标出的透明占位。它的窗口应盖住这块占位，标题栏按钮不再挡在格子里。
5. 点这个窗口里的输入框或按钮，确认点得到，焦点在对方应用里，而不是穿透到下面的网页。
6. 格子顶上的「拆卸」留在占位外面，仍然点得到。正在跟随的那一行显示「跟随中」，不会再发一次吸附。

占位只覆盖格子标题以下的区域。壳窗口本身不透明，其他格子和标题栏不受影响。

## 跟随

吸附之后：

1. 拖动 UniWorkspace 主窗口。对方应跟着走。拖动过程中可以有一条很窄的缝，松手后应盖住占位，不留在旧位置。
2. 拖动主窗口边缘改变大小，或切换单窗 / 1:1 / 田字格。占位变了之后，对方的大小跟着变。
3. 把主窗口拖到另一块显示器上。对方应跟到那一块屏幕，刷新跟那块屏幕走。
4. 再拖回原来的屏幕。两者仍在一起，点得到。

## 全屏

1. 先让目标应用进入全屏，再点「吸附」。它应退出全屏，对齐到格子里，并且可以点击。
2. 拆卸。如果它吸附前是全屏，全屏状态回到吸附前；边框和层级一起回来。
3. 先在普通窗口里吸附，再点 UniWorkspace 的绿色按钮让主窗口全屏。对方应出现在主窗口所在的全屏空间里，并盖住占位。
4. 退出主窗口全屏。对方仍跟着普通窗口，没有留在全屏空间里。

如果系统不允许退出全屏，吸附会改成窗口并列跟随，或在还原边框后停下来。不能留下一个无边框、又脱离格子的窗口。

## 多个桌面空间和空间边缘

1. 吸附之后，用触控板或 Mission Control 把主窗口切到另一个 Space。对方应出现在主窗口所在的那个空间。
2. 把主窗口拖到两个 Space 的交界并停住，先不要松手让系统完成切换。对方应留在当前空间，不要提前跳进旁边那个空间。
3. 完成切换后再看。两者在新空间里仍叠在一起。
4. 切回原来的空间。两者一起回来。

如果系统不允许改空间，位置跟随仍在，侧栏不会因此把窗口丢掉。

## 对方先退出

1. 吸附一个已确认的桌面应用。
2. 用该应用自己的退出（例如 Cmd+Q），不要强制杀掉 UniWorkspace。
3. 格子里的透明占位消失，下面的网页重新出现。侧栏说明这个应用已退出或窗口已关闭，吸附结束。
4. 屏幕上不再有那个应用的无边框窗口。Dock 里也不应留下一个没有边框、关不掉的空窗。
5. 再打开同一个应用。它以自己的普通窗口出现，不会自动被吸回去，边框也在。

如果退出时边框没有写回去，但窗口还在，`snap-recovery.json` 会留着，下次正常启动再试。窗口已经不在时，这份记录会删掉，避免下次启动去改一个新窗口。

## 拆卸

1. 点格子上的「拆卸」，或把布局收成不再包含这一格，或清空这一格。
2. 标题栏和窗口按钮回来。
3. 窗口回到吸附前的位置和大小，不再强制盖在 UniWorkspace 上面。
4. 侧栏出现「已还原边框和层级。」
5. 如果这一格下面本来有网页，拆卸后网页重新出现。

关闭 UniWorkspace 的红色按钮也会做同一次还原。

如果进程在吸附中被强制杀掉，下一次正常启动会读 `~/Library/Application Support/com.uniworkspace.ai/snap-recovery.json`，把边框和位置放回去，然后删掉这个文件。不要手改这个文件。辅助功能还没打开时，文件会留着，等授权之后再试。

## 并列跟随

如果辅助功能读得到窗口，但不允许去掉边框，或写不进占位矩形：

1. 格子里会说明已经改为在主窗口旁边跟随，边框还在。
2. 窗口出现在主窗口右侧；右侧不够时改到左侧。
3. 拖动、缩放主窗口和切换空间时，它仍跟着走，并且可以点击。
4. 拆卸后它回到吸附前的位置。边框本来就没有被去掉。

如果连旁边的位置也不允许写，窗口留在原处，侧栏说明没有移动它。

## 辅助功能被拒绝

1. 点「仅使用网页」，或者在系统对话框里不允许。
2. 点任意已确认桌面应用的「吸附」。
3. 侧栏说明需要辅助功能，并写明这个窗口没有被移动。它停在原来的位置，边框也不变。
4. 侧栏点 ChatGPT 或 Claude 网页，分屏、登录和自定义链接仍可使用。应用不退出。

启动时不会自己弹出系统授权。

## 指定窗口仍然不动

1. 点「指定窗口」，把任意可见窗口加入侧栏。
2. 那个窗口的位置、大小和层级都不变。
3. 这一行没有「吸附」。指定只是列出。未确认 Bundle ID 的应用也没有「吸附」。

## 不要回归的部分

Claude Desktop 的吸附、跟随、点击和拆卸仍在。已确认网页的分区、登录态、单窗 / 1:1 / 田字格，以及只重建崩溃的那一格，都还在。ComfyUI 仍只打开 `http://127.0.0.1:8188/`。全局热键仍未注册。

## 这一周明确不做

不做全局热键，也不做 Option+Space。不做安装包。不做窗口镜像，不做广播提问、YAML 市场、OCR、VLM 或 ComfyUI 工作流自动化。不做 Windows 或 Linux 构建，也不做公证。同一时间只跟随一个原生窗口；同时吸附多个留到后面的热键周再定上限。
