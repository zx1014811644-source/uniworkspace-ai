# Week 4：桌面检测、辅助功能与本机端口

这些步骤要在 macOS 13 或更高版本上执行。Linux 上的 `pnpm dev` 只能看壳，不会扫描桌面应用，也不会探测端口。

```bash
pnpm install
pnpm tauri dev
```

退出时点窗口左上角的红色关闭按钮，确认进程已经结束，再执行下一次 `pnpm tauri dev`。

检测大约每 1 秒做一次。一次探测本身留了 200 毫秒的余量，所以一个已确认的桌面应用启动后，侧栏最迟在 2 秒内出现「运行中」。轮询间隔写在 `SCAN_INTERVAL_MS`，前端不会把它拉长到 1 秒以上。

## 已确认的桌面应用

只认 `catalog/apps.json` 里 `bundleIdStatus` 已经是 `confirmed` 的 7 个 Bundle ID：

- ChatGPT Desktop `com.openai.codex`
- Claude Desktop `com.anthropic.claudefordesktop`
- LM Studio `ai.elementlabs.lmstudio`
- Gemini Desktop `com.google.GeminiMacOS`
- Kimi Desktop `com.moonshot.kimichat`
- 豆包 Desktop `com.bot.pc.doubao`
- Cursor Desktop `com.todesktop.230313mzl4w4u92`

实现读的是 `NSWorkspace` 正在运行的应用的 Bundle ID。进程名只在同一个 Bundle ID 有多条记录时用来挑选，不能单独促成一次匹配。WorkBuddy、Accio Work、Harness 的 Bundle ID 仍是空的，即使进程名对得上也不会出现在「运行中」。

核对：

1. 先退出一个已经安装的、上表里的应用，例如 Cursor 或 ChatGPT。
2. 看侧栏「桌面 → 运行中」。它不应该还列着这个应用。目录行应是「未运行」。
3. 再启动这个应用。
4. 2 秒内，「运行中」出现对应的一行，目录行变成「运行中」。点这一行只会说明这一周不吸附，窗口不会被挪走。
5. 再退出它。「运行中」里的这一行会消失。

机器上没装某个应用时，跳过那一条即可。不要为了让检测变绿去改目录里的空 Bundle ID。

## 辅助功能

内容区顶部有一段说明。它不是挡住整个窗口的对话框，侧栏和分屏可以同时使用。

干净的第一次：

1. 删掉 `~/Library/Application Support/com.uniworkspace.ai/a11y.json`。不要删同目录的 `workspace.json`，否则上周的布局和自定义链接会一起丢。
2. `pnpm tauri dev`。
3. 读完说明，点「请求系统授权」。系统对话框出现后选择允许。
4. 如果对话框关掉了但开关仍是关的，点「打开辅助功能设置」，在「隐私与安全性 → 辅助功能」里打开 UniWorkspace AI，再点「重新检查」。
5. 状态变成「已授权」后点「完成」。说明会收起。选择写在 `a11y.json`。

未签名的 debug 构建如果换了产物路径，系统可能把它当成新应用，开关要重新打开。这不是崩溃。

拒绝：

1. 点「仅使用网页」，或者在系统对话框里不允许，再点「仅使用网页」。
2. 说明收起。侧栏点 ChatGPT 或 Claude，分屏、登录、自定义链接和「检查隔离」仍可使用。
3. 应用不会退出。之后可以从侧栏「辅助功能」再打开这段说明。

启动时不会自己弹出系统授权。只有点「请求系统授权」才会带上提示选项。

## 指定窗口

1. 在侧栏点「指定窗口」。
2. 列表来自当前屏幕上的普通窗口，不需要先授予辅助功能。本应用自己的窗口不会列出来。
3. 点「加入侧栏」。这一行留在「指定窗口」下面，标成「可见」。
4. 那个 macOS 窗口应停在原来的位置，大小也不变。
5. 关掉那个窗口后，侧栏这一行变成「已关闭」。点「移除」可以把它从侧栏拿掉。

窗口标题在没有屏幕录制权限时可能是空的，这时只显示应用名。这一周不申请屏幕录制。不在目录里的应用也可以指定；指定只是列出，不会写入分屏，也不会吸附。

列表最多 200 个窗口。窗口编号在对方进程还活着时有效，退出 UniWorkspace 后不保留。

## 本机端口

侧栏「本机端口」探测 `127.0.0.1` 上的三个端口，连上就标「运行中」，连不上标「未运行」。探测只做 TCP 连接，不发送 HTTP，也不提交工作流。

- ComfyUI `127.0.0.1:8188`
- Ollama `127.0.0.1:11434`
- LM Studio 本地服务 `127.0.0.1:1234`

只在 ComfyUI 处于「运行中」时提供「打开」。它把 `http://127.0.0.1:8188/` 放进当前格子的网页视图，和手动「添加到独立分区」用的是同一条路。11434 和 1234 没有打开按钮。

只监听 IPv6 `::1`、不监听 `127.0.0.1` 的服务会显示「未运行」。

## 不要回归的部分

Accio Work、Cursor、Harness 的网页地址保持为空。WorkBuddy、Accio Work、Harness 的桌面 Bundle ID 保持为空。
